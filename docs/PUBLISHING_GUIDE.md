# Book Publication Editorial Checklist

Every book requires a verified title, author list, publisher, publication year (if known), ISBN/eISBN (if assigned), description and permission to use the cover. Save unpublished titles as **Draft**.

## Decide the distribution model

1. **Metadata / inquiry** — announce a book, show summary and verified information, provide an inquiry address. Does not imply public file rights.
2. **External purchase** — show verified book information and send readers to the publisher, bookstore or authorised vendor using `external_url`. No payments are taken on this site.
3. **Authorized free edition** — only after explicit author/publisher rights clearance, upload a full PDF and set rights to `authorized` and access to `free`. Readers can open or download the PDF.

## Editable book fields

Title, author(s), type (book/chapter), year, publisher, ISBN, edition, format, category, summary/abstract, cover image URL/upload, sample PDF, optional full PDF, external sales URL, rights, visibility.

## Publication workflow

**Draft → Metadata verified → Cover and digital rights verified → Sample reviewed → Published → Periodic updates**

If publishing the professor's books in PDF, include copyright and licensing details inside the book. Ensure that cover art, excerpts and chapter contents are original or separately licensed. For books distributed by third-party publishers, a link to the publisher is often safer than self-hosting the full text.

## Images and accessibility

For best results, use book covers roughly 800×1100 pixels or another sharp portrait format. Use clear, high-contrast typography and meaningful cover alt text. Upload an official academic portrait only after permission is granted.

## Optional future commerce capabilities

A later release can add order checkout, inventory, taxes, shipping and customer entitlements. The present site intentionally leaves these off until a payment provider, fulfilment method, merchant policies and ownership approvals are confirmed.
